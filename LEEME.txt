MACRO DEMO 2.0 — PWA instalable

Esta es una aplicación web progresiva (PWA), no un APK. Es un simulador independiente, no afiliado a Banco Macro. La identificación DEMO permanece visible. Todos los datos son ficticios; no ingreses credenciales ni datos bancarios reales.

PUBLICACIÓN EN GITHUB PAGES
1. Extraé el ZIP.
2. En tu repositorio GitHub, usá Add file > Upload files.
3. Subí el contenido completo, incluyendo index.html, manifest.json, sw.js y la carpeta icons. Reemplazá los archivos anteriores cuando GitHub lo solicite.
4. Confirmá con Commit changes.
5. En Settings > Pages verificá Branch main y carpeta /(root).
6. Esperá a que termine el despliegue y abrí la dirección HTTPS del repositorio.
7. En Chrome Android: menú ⋮ > Instalar aplicación o Añadir a pantalla principal.

FUNCIONES
- Acceso local con cualquier usuario y clave de prueba.
- Inicio, resumen, cuenta sueldo simulada y movimientos.
- Filtros por fechas, tipo y texto.
- Edición de titular, saldo y número ficticio de cuenta.
- Alta de movimientos ficticios y guardado local en el navegador.
- Caché para uso sin conexión después de la primera visita HTTPS.
